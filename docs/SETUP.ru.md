# Grok Voice на iPhone — настройка

1. **Открыть в Safari:** https://erik-balfe.github.io/voice-input-web/
2. **На экран «Домой»:** кнопка «Поделиться» → «На экран „Домой“» → включить «Открыть как веб-приложение» → «Добавить».
   Дальше открывайте только с иконки (у веб-приложения своё хранилище, отдельное от Safari).
3. **Вход:** в приложении «Настройки» → «Войти через xAI» → «Открыть xAI» → подтвердить код → вернуться в приложение (вход завершится сам).
4. **Микрофон:** нажмите большую кнопку, разрешите доступ. Если iOS спрашивает каждый раз:
   Настройки iPhone → Приложения → Safari → Микрофон → «Разрешить» (или в Safari: «аА» → Настройки веб-сайта → Микрофон → Разрешить).
5. **Работа:** нажали → говорите → нажали «Стоп». Текст распознаётся и сам копируется в буфер; вставьте его в Telegram. Если автокопирование не сработало — кнопка «Скопировать».
   «Чистка текста» — исправление и сокращение через Grok (вкл./выкл.).

## Быстрый запуск (Команды)

Приложение «Команды» → «+» → действие «Открыть URL»:
- основной вариант: `webapp://erik-balfe.github.io/voice-input-web/?autostart=1` (откроет именно веб-приложение с экрана «Домой», если iOS поддерживает эту схему);
- если не сработало — `https://erik-balfe.github.io/voice-input-web/?autostart=1` (откроется в Safari: вход и история там отдельные, понадобится войти ещё раз).

Назначение:
- **Кнопка действия** (у iPhone 16e она есть): Настройки → Кнопка действия → «Команда» → выбрать команду.
- **Касание задней панели:** Настройки → Универсальный доступ → Касание → Касание задней панели → Двойное/тройное касание → команда.

`?autostart=1` начинает запись сразу, если доступ к микрофону уже выдан; иначе — одно касание кнопки.
